WorkBuddy 隐私政策 / Privacy Policy

最后更新 / Last updated: 2026-11-25

1. 应用性质 / What this app is

WorkBuddy 是作者本机运行的个人自动化工具，非商业、非公众服务，仅供作者本人使用。WorkBuddy is a personal automation tool that runs locally on the author's own computer. It is not a commercial product and is not offered to the public.

2. 访问的数据范围 / Data accessed

经 OAuth 授权后，应用仅访问作者本人 Google 账号下的日历数据（https://www.googleapis.com/auth/calendar）：读取日历列表与事件、创建与更新作者自己的日历事件。不访问 Gmail、云端硬盘、联系人或其他任何 Google 服务的数据。With the author's OAuth consent, the app accesses only the author's own Google Calendar data (scope auth/calendar): listing calendars and events and creating/updating the author's own events. No Gmail, Drive, Contacts, or any other Google data is accessed.

3. 数据存储 / Storage

所有数据仅保存在作者本机（一台个人电脑）的本地文件中，不上传、不传输到任何第三方服务器，也不存入云数据库。OAuth refresh token 保存在本机配置文件中，仅用于自动续期访问。All data stays in local files on the author's own computer. Nothing is uploaded or transmitted to any third-party server or cloud database. The OAuth refresh token is stored in a local configuration file and used only to renew access automatically.

4. 数据共享 / Sharing

不向任何第三方出售、出租或共享数据；不使用分析、广告或跟踪服务；不含任何第三方追踪脚本。No data is sold, rented, or shared with third parties. No analytics, advertising, or tracking services are used. This site contains no third-party tracking scripts.

5. 数据保留与删除 / Retention and deletion

本地数据保留至作者主动删除。删除方式：删除本机保存的凭证与数据文件，并在 Google 账号的「第三方应用与数据」页面撤销本应用的访问权限即可；撤销后应用不再能访问任何日历数据。Local data is retained until the author deletes it. To delete: remove the local credential/data files and revoke this app's access at Google Account → Security → Third-party apps; after revocation the app can no longer access any calendar data.

6. 儿童隐私 / Children

本应用不面向儿童，也不会有意收集儿童数据。This app is not directed to children and does not knowingly collect data from children.

7. 变更 / Changes

本政策如有更新，将直接更新本页面并修改上方日期。Any change will be published on this page with an updated date above.
