WorkBuddy

WorkBuddy is a personal, locally-run automation tool. It runs on the author's own computer and uses the Google Calendar API only to create and read the author's own calendar events, so that the author's daily work log is archived into their own calendar.

WorkBuddy 是运行在作者本机的个人自动化工具。它通过 Google Calendar API 读写作者本人的日历，用于把每日工作记录归档到自己的日历中；不提供面向公众的服务，也不收集他人的数据。
